# نسخه بازطراحی صفحه اصلی آبان

- فایل `index.html` بازطراحی شده و از `home-redesign.css` و `home-redesign.js` استفاده می‌کند.
- فایل‌های قبلی (پنل مدیریت، فرم ثبت مسئله، مجله و شبکه شرکت‌ها) تغییر نکرده‌اند.
- صفحه نخست کارت‌های **شرکت‌های منتشرشده** و **مطالب منتشرشده مجله** را به صورت عمومی و زنده از جداول موجود Supabase دریافت می‌کند. RLS و سیاست SELECT عمومی باید به درستی تنظیم شده باشند.
- فرصت‌های همکاری به صورت جایگاه ثابت حفظ شده‌اند، اما پنل فعلی جدول عمومی و رابط انتشار فرصت ندارد. تا تکمیل این بخش، پیام وضعیت خالی نشان داده می‌شود. `opportunities.html` صفحه مقدماتی است، نه فهرست قابل مدیریت.
- خدمات چهارگانه فعلاً محتوای ثابت هستند و در فایل `services.html` نیز توضیح دارند. پنل موجود ماژول ویرایش خدمات ندارد؛ برای مدیریت خدمات از پنل، به جدول و ماژول جدید نیاز است.
- معرفی توانمندی فعلاً به فرم Google Forms فعلی لینک دارد؛ فرم ثبت مسئله به `problem.html` وصل است.
- فایل‌های موجود در ریشه پوشه را بدون تغییر مسیرها در ریشه مخزن GitHub Pages بارگذاری کنید.
- در صورت تمایل به همسان‌سازی کامل سایر صفحات، CSS آن‌ها باید جداگانه یکپارچه شود.
- کارت نمونه با عنوان ساختگی در صفحه عمومی درج نشده و اطلاعات واقعی تنها پس از انتشار نمایش داده می‌شوند.
