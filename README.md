# آبان | Aban

وب‌سایت استاتیک آبان روی GitHub Pages با داده‌های شرکت‌ها و مسائل در Supabase.

## فایل‌های اصلی

- `index.html`: صفحه اصلی
- `problem.html`: فرم عمومی ثبت مسئله (فقط ذخیره در Supabase؛ انتشار عمومی ندارد)
- `companies.html`: شبکه عمومی شرکت‌ها (فقط رکوردهای منتشرشده)
- `company.html`: پروفایل عمومی هر شرکت بر اساس `?slug=...`
- `dashboard.html`: داشبورد یکپارچه مدیریت شرکت‌ها و مسائل با مجوزهای مبتنی بر نقش
- `aban-unified-theme.css`: قالب نمایشی صفحه اصلی و شبکه شرکت‌ها
- `aban_hero.png`: تصویر مورد انتظار قالب (اگر در مخزن فعلی موجود است، آن را نگه دارید؛ در فایل‌های ارسالی حاضر نبود)

## فایل‌های قدیمی قابل حذف پس از آزمون

- `companies-dynamic.html`: فهرست پویای تکراری؛ جایگزین آن `companies.html` است
- `admin.html`: پنل قدیمی مستقل مسائل؛ ابزار مشابه در `dashboard.html` است
- `companies-admin.html`: پنل قدیمی مستقل شرکت‌ها؛ ابزار مشابه در `dashboard.html` است
- `companies/sabzineh.html`: پروفایل نمایشی فرضی؛ اکنون شرکت‌های واقعی با `company.html?slug=...` نمایش داده می‌شوند

**احتیاط:** پیش از حذف صفحات، لینک‌های بیرونی/نشانک‌ها را هم بررسی کنید. حذف صفحه، آدرس‌های قدیمی را 404 می‌کند. تصویر `aban_hero.png` را اگر وجود دارد حذف نکنید.

## نکات امنیتی

کلید Publishable کلید عمومی است. هرگز Secret Key یا service_role را به مخزن اضافه نکنید. امنیت داده‌ها باید با RLS در Supabase اعمال شود؛ پنهان‌کردن پنل امنیت کافی نیست.
